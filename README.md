# Student Information Management System

## Files
- index.html — structure and UI
- style.css — styling and responsive layout
- script.js — form handling, table, search and CRUD

## Daily development order
1. Day 1: Set up project and design front-end interfaces.
2. Day 2: Create student information submission forms.
3. Day 3: Create students' table and UI components.
4. Day 4: Create CRUD simulation (Create, Read, Update, Delete).
5. Day 5: Test and complete the front end.

This is a front-end CRUD simulation. It uses browser localStorage instead of a real server/database backend. A true full-stack version would add a backend API and database.
